[size=13]Bonjour à toute la communauté !

Le développement du [b]SimCraft Engine (SCE)[/b] continue d'avancer. Après avoir posé les bases modulaires, cette mise à jour se concentre sur deux aspects cruciaux : donner une "intelligence" comportementale aux acteurs et moderniser l'interface utilisateur.

L'objectif reste le même : [b]Sortir des carcans de RPG Maker pour offrir des mécaniques de simulation profondes.[/b]

Le SCE n'est pas un simple pack de plugins, mais une véritable [b]architecture applicative[/b] qui repense la manière dont les fonctionnalités sont développées et intégrées.[/size]

[center][size=18][u][color=Crimson]La Philosophie du Moteur[/color][/u][/size][/center]

Le cœur du SimCraft Engine repose sur trois piliers fondamentaux :

[quote]
• [b]Modularité[/b] : Chaque fonctionnalité est un module indépendant qui déclare ses propres besoins (dépendances, fichiers de données, etc.). Fini les scripts monolithiques !

• [b]Déclaration[/b] : Un module ne dit pas au moteur [i]comment[/i] faire les choses, mais [i]ce dont il a besoin[/i]. Le moteur se charge ensuite de tout orchestrer.

• [b]Centralisation[/b] : La logique complexe de chargement, de sauvegarde et de débogage est gérée à un seul endroit, le [b]SystemLoader[/b], rendant le système prévisible et facile à maintenir.
[/quote]

[center][size=18][u][color=Crimson]🔥 Nouveautés de la Mise à Jour[/color][/u][/size][/center]

[b]1. Le Nouveau Système d'Activités : L'Architecture "Marionnettiste"[/b]

Jusqu'à présent, la gestion des besoins (Faim, Soif, Fatigue) était mélangée avec la gestion des actions. C'était fonctionnel, mais rigide. Nous avons tout repensé pour introduire le [b]Module Activity[/b].

Imaginez que votre personnage est une marionnette :
• [b]ActorAnimManager[/b] est le corps (il bouge, joue les animations).
• [b]ActorHealthManager[/b] est le bilan de santé (il stocke les valeurs de faim, fatigue...).
• [b]ActorActivityManager[/b] est désormais le [b]Cerveau[/b].

Une activité (comme "Dormir", "Se Laver", ou bientôt "Récolter") prend temporairement le contrôle du personnage. Elle pilote l'animation et modifie les stats en temps réel, frame par frame. Cela permet un découplage total et une extensibilité infinie.

[b]2. Interface : Le Ring Menu (Menu Circulaire)[/b]

L'interface utilisateur (UI) reçoit un lifting moderne avec l'arrivée du [b]Window_RingCommand[/b].
• [b]Design Circulaire[/b] : Les options s'affichent en cercle autour du personnage ou de la souris.
• [b]Adaptatif[/b] : Le rayon du menu se calcule dynamiquement pour s'adapter à la taille de l'écran.
• [b]Optimisé[/b] : Fluidité parfaite (60 FPS) même avec des animations d'ouverture complexes.

[b]3. Immersion Physique & Visuelle[/b]

Le SCE pousse le détail jusqu'à la physiologie de vos héros :
• [b]Souffle & Élan[/b] : Un nouveau système d'endurance gère le souffle (`Breath`) et l'élan (`Impulse`), influençant dynamiquement la distance de saut et la capacité à courir.
• [b]Paper-Doll 2.0[/b] : Le système d'apparence devient plus intelligent. Il gère désormais nativement les attributs raciaux (queues, ailes) et adapte visuellement les équipements à la morphologie du personnage (poids/musculature) en temps réel.

[center][size=18][u][color=Crimson]Comment ça marche ?[/color][/u][/size][/center]

[b]Exemple : Créer une activité "Dormir"[/b]
Voici à quoi ressemble la logique pour faire dormir un personnage avec le nouveau système. C'est lisible, même pour un néophyte :

[code]
class SleepActivity extends ActivityBase {
    onStart() {
        // Le cerveau dit au corps : "Joue l'animation dormir"
        this.mainManager.animator.playAction('sleep');
    }

    update() {
        // À chaque instant, on régénère la forme
        this.mainManager.health._form += 0.1;

        // Si la forme est à 100%, le cerveau décide de se réveiller
        if (this.mainManager.health.getForm() >= 100) {
            this.finish();
        }
    }
}
[/code]
